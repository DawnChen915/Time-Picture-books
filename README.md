# 时光绘本

每一段时光，都有一本属于 TA 的书。绘本按孩子的成长阶段分类，有两种：

- **现成绘本**：不需要角色，免费读，比如给 1–3 岁的几何认知绘本。插图是代码画的 SVG，不调用生图服务。
- **定制绘本**：一家人当主角。家人的信息和卡通形象填一次就保存下来，之后每本都直接用；按模板把每一页画出来，可以在线翻看并导出 PDF。

前期为控制成本，定制绘本的故事是固定模板（只替换宝宝的名字），只有插图是生成的；等验证了用户愿意付费，再做每本独一无二的故事。

## 快速开始

```bash
npm install
cp .env.example .env.local   # 填入 OPENAI_API_KEY
npm run dev                  # http://localhost:3000
```

不填 `OPENAI_API_KEY` 时会自动使用占位图，可以不花钱把流程走一遍。想看失败和重试的样子，可以设 `PLACEHOLDER_FAIL_RATE=0.5`、`PLACEHOLDER_DELAY_MS=2000`。

### 一直转圈 / 生成失败怎么办

1. 运行 `npm run check:openai`，它会检查 key 有没有读到、能不能连上 OpenAI、能不能用配置的图像模型（不会生成图片，不花钱）。
2. 在国内需要代理：Node 不会自动使用系统代理，要在 `.env.local` 里加 `HTTPS_PROXY=http://127.0.0.1:端口`（你的代理软件的 HTTP 端口），然后重启 `npm run dev`。
3. 运行 `npm run dev` 的终端会打印每张图的 `[images] ... start attempt / done / failed`，失败原因也会显示在页面上。
4. 改了 `.env.local` 之后要重启 `npm run dev` 才会生效。

## 页面

| 路径 | 内容 |
|---|---|
| `/` | 选绘本：按「咿呀时光 0–3 岁 / 好奇时光 4–6 岁 / 成长时光 7 岁以上」排成时间轴，标出宝宝现在所在的阶段 |
| `/library/:id` | 读现成绘本 |
| `/create/:templateId` | 做定制绘本。有家人档案时不用再填任何东西，只缺的家人才要上传照片 |
| `/books` | 时光书架：这个家庭做过的绘本，按做书时宝宝的年龄分组 |
| `/books/:id` | 翻看定制绘本，画图进度、失败重试、导出 PDF |
| `/family` | 家人档案：改宝宝的名字/年龄/性别，添加或更新每个人的卡通形象 |

## 定制绘本的生成流程

1. **家人档案**（`/family` 或做书表单）：宝宝信息和每人的卡通形象按"家庭"保存，浏览器记住家庭 ID。改年龄不会自动重画形象（重画要花钱），需要时在档案里点"更新形象"。
2. **更新形象**（`PUT /api/families/:id/members/:role` → `POST /api/families/:id/avatars/:role`）：上传新照片就按新照片画；不传照片时用现在的形象作参考，按描述修改（"换成短头发"），人物还是同一个人。原始照片在形象画好后删除。
3. **创建绘本**（`POST /api/books`）：按模板生成每页文字，记下做书时宝宝的年龄。
4. **画插图**（`POST /api/books/:id/illustrations/:slot`）：封面和每一页都把出场人物的形象作为参考图传给 gpt-image，保持人物一致。前端同时画 2 页。

### 失败重试

- **服务器自动重试**：超时、网络错误、429、5xx、偶发的安全拦截会自动重试（默认共 3 次，间隔 3 秒、10 秒），页面上显示"正在自动重试（第 N 次）"。key 无效、额度用完、参数错误这类重试也没用的错误会直接失败，并说明原因。次数用 `IMAGE_MAX_ATTEMPTS` 调整。
- **手动重试**：失败的页有"重新画这一页"；顶部有"重画失败的 N 页"，会按同时 2 页的节奏重新排队。形象失败时有"重新生成"。
- **请求没到达服务器**（网络断开、服务器重启）时，页面会显示原因和重试按钮，而不是一直转圈。

## 现成绘本

在 `src/library/`：`art.tsx` 是共用的画图零件（圆圆、三角、方方三个形状朋友，太阳、云、星星等），`geometry.tsx` 是几何绘本。每页一两句短话，文字里的 `\n` 是换行。新增一本只需要往 `LIBRARY` 里加一项，填 `stage` 和 `ages` 就会出现在对应的时光阶段里。

| 绘本 | 适合 | 页数 |
|---|---|---|
| 圆圆，圆圆 | 1–2 岁 | 6 |
| 尖尖三角形 | 2–3 岁 | 6 |
| 方方正正 | 2–3 岁 | 6 |
| 形状拼一拼 | 2–3 岁 | 7 |

## 定制模板

模板都在 `src/templates/index.ts`：文字里的 `{name}` 会替换成宝宝的名字；`scene` 是英文画面描述，用 CHILD / MOM / DAD 指代人物；`cast` 列出这一页出场的人，决定传哪些形象作为参考图；`stage` 和 `ages` 决定放在哪个时光阶段。

| 模板 | 主角 | 适合 | 页数 |
|---|---|---|---|
| 妈妈的魔法拥抱 | 宝宝、妈妈 | 2–4 岁 | 7 |
| 宝宝的勇敢小脚丫 | 宝宝 | 3–5 岁 | 6 |
| 我们一家去海边 | 宝宝、妈妈、爸爸 | 3–6 岁 | 8 |

时光阶段的划分在 `src/lib/stages.ts`。

## 成本（每本定制绘本）

- 形象：每人 1 次生图，复用时为 0
- 插图：封面 + 每页各 1 次，现有模板是 7–9 次
- 自动重试会多调用几次：返回错误的请求一般不收费，但超时的那次 OpenAI 那边可能已经画完并计费
- 现成绘本：0
- 不调用大语言模型

## 目录

```
src/
  app/                    页面与 API 路由
  components/             表单、翻书组件（Flipbook）、阅读器、书架、家人档案、PDF 导出
  library/                现成绘本（SVG 插图）
  templates/              定制故事模板
  lib/
    images/               图像服务（openai / placeholder）与重试，换服务只需加一个 provider
    illustrate.ts         形象与插图的生成流程、提示词
    members.ts            家人形象的更新（照片、描述、旧形象作参考）
    stages.ts             时光阶段
    storage.ts            本地文件存储（.data/families、.data/books）
```

## 现阶段的限制

- 数据存在本地磁盘，没有数据库、登录和付费；部署到 Serverless 平台前需要换成对象存储。
- "家庭"只靠浏览器里保存的 ID 识别，换设备就找不到之前的形象和书架。
- 画图由打开的绘本页面驱动：做完书关掉页面，没画的页要等下次打开时继续画。
